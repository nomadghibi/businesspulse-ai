# AI Safety

AI must:
- Use only organization-scoped data.
- Include data sources used.
- Include assumptions.
- Include confidence.
- State missing data clearly.
- Avoid unsupported causal claims.

AI must not:
- Fabricate metrics.
- Access another organization’s data.
- Run DELETE, UPDATE, DROP, ALTER, or INSERT.
- Send emails/SMS or change ad budgets without approval.
